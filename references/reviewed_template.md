# 经审核的学校模板适配

2026-11-07 新增 `scripts/reviewed_template.py`。该入口将明确审核的段落清单应用到学校模板，保留封面、媒体、表格内容和学术文本。它不是任意学校模板自动识别器。

本次适配限定原稿四节结构：封面、摘要、正文首节、正文后续节。其他分节结构会停止，需要扩展适配器并重新检查。页边距修正是本次用户确认后的模板配置，不是所有学校的默认值。

运行方式（从 paperfit 项目根目录）

```sh
python scripts/paperfit.py reviewed-template 原稿.docx 审核配置.json 新文件.docx
python -m unittest discover -s tests -v
```

审核清单包含原文件 SHA-256、原始 body 块索引与原文、目标样式、明确删除的格式说明后缀、图片及表格位置、表头行数、必要的图片缩放比例。原文件变化后必须重新审核，不能把旧清单套到新版本上。脚本拒绝覆盖输出文件，已处理文件也不能套用原清单，避免重复目录和题注。

支持的规则

- 标题使用 Word 原生 heading 1/2/3，正文使用独立“论文正文”，参考文献用“参考文献正文”。用户已确认后续“参考文献”标题按一级标题处理。
- 样式的 eastAsia 使用宋体，ascii/hAnsi 使用 Times New Roman。字号、行距、首行缩进、粗体在段落样式中定义。
- 格式说明仅按审核清单中的完整后缀删除。正文其他括号、表达和已有标题编号保持原样。
- 图表题注使用同一个 Caption 样式和各自的原生 SEQ 序列，注册“图”“表”标签。没有题注文字时仅生成编号，不编写内容。
- 清单中的题注可用 `caption_index` 指向原有手打题注，转换其数字为 SEQ，不再追加重复题注。移动题注时，将其携带的分节边界留在原位置。输出前默认执行[原生引用与文献列表转换](native_references.md)，可用顶层 `native_references: false` 明确关闭。
- 表格用原生表格/单元格边框形成三线表，覆盖模板遗留边框；不依赖 WPS 虚线网格显示。当前边框由适配器设置，改表头行数或整表线宽时需重跑适配器，不应只修改表格样式名称。
- 目录是可更新的原生 TOC 域。封面非章节大纲可在清单中明确排除，防止校名进入目录。
- 一级标题 nextPage 分节，各节页眉页脚独立。封面和目录不显示页码，摘要用罗马数字，正文从 1 开始连续编号。
- 继承同页处理；新增 90°、180°、270° 原生图片旋转支持，保持旋转参数并只等比例缩小显示尺寸，不改媒体数据。

限制与验证

- 仍需人工审核模板结构、括号说明、表头行数和目录范围。复杂合并表头、浮动对象、跨页长表不能据本次样例宣称全面兼容。
- Word 或 WPS 负责最终分页；生成后更新整个目录并检查每页。已保存的新文件仍须重新核对文字、媒体、样式及域，不能只检查 Python 输出。
- 原稿无公式，本次学校模板验收没有覆盖公式；公式的既有回归测试继续保留。
- 表1和表2在素材中均为空表，保留空白，不补写数据或文献内容。

三线表线宽采用顶底线 1.5 磅、栏目线 0.75 磅，依据[广西医科大学论文要求](https://yjs.gxmu.edu.cn/tzgg/P020220527598139251134.pdf)。只参考其三线表线宽，字体和行距遵循当前用户规则。
