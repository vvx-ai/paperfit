# 图表题注同页与一级标题分节

此项目已确认两项持续执行的规则。图表题注与对应对象同页。一级标题从新页开始，使用下一页分节符，使目录及各正文节的页眉页脚可以分别编辑。

2026 年 11 月 7 日，用户进一步确认页码按目录与正文分开处理。目录采用独立节，沿用已验收的隐藏页码设置。正文首页从 1 开始，各章接续正文页码。一级标题分节用于另页及独立页眉页脚，正文页码跨章连续。

## 调用

```sh
python3 scripts/paperfit.py flow INPUT.docx OUTPUT.docx
python3 -m unittest discover -s tests -v
```

输入使用已经排版并核对结构的 DOCX，输出及旁边的 JSON 报告须使用新路径。已有目录通过 Word 的“更新整个目录”重新计算页码。生成新目录及正文页码时，按 toc、paginate、flow 顺序执行，最后用排版应用更新目录并保存。核心调用为 `page_flow.enforce(source, output)`。

## 规则如何生效

题注通过已有相邻匹配规则定位。图下题注由图片段落的“与下段同页”绑定，图上题注由题注绑定后续图片。短表设置行内禁止跨页和段落连续约束，并将其连接到题注。题注继续使用原题注样式，统一保留文字字体、字号、编号域和交叉引用。

独立嵌入式图片支持无旋转和 90°、180°、270° 直角旋转。图片过高时，根据纸张可用区域预留题注空间，等比例缩小显示尺寸。报告记录缩放前后的尺寸，媒体文件本身保留。实际分页以 Word/WPS 检查结果为准。

文档设置关闭自动图片压缩。本轮发现 Word 会在保存缩小的图片时重采样，关闭该设置后已验证保存仍保留原始媒体数据。

一级标题样式启用段前分页、与下段同页、段中不分页。现有一级标题前复用或添加分节边界，正文各章继续原有页码序列。二三级标题启用与下段同页和段中不分页，避免孤立在页末。对下级标题及其他段落核对一级标题分页属性的继承影响。

各节的默认、首页和偶数页页眉页脚采用独立部件，复制原来有效的内容和相关关系。目录和各章可以单独修改页眉页脚。已有首页、奇偶页开关依照原文设置。

## 后续编辑

新增一级标题应用相同标题样式时，会继承段前分页。新增分节边界，以及新图表与新题注的关联，需要再次执行 flow。移动题注、修改纸张或大幅修改内容后，也应重新执行并检查打印预览。此 Skill 在每次交付前执行这些检查。

## 范围与验收

当前处理正文直属且唯一相邻的图表与题注。浮动图片、混合文字图片段落、嵌套或浮动表格、多栏版面、跨节对象和无法唯一匹配的题注列为待检查。长表高度通过估算提示，最终须实际排版确认。超过一页的完整表格需要另行调整页面布局或采用续表方案。

自动测试覆盖图上图下题注、图像等比缩放、表格连续约束、章节分节、页码连续、独立页眉页脚、下级标题继承、重复执行、修订输入及输出保护。

在 Word/WPS 打印预览逐页核对每个图表与题注，确认所有一级标题在新页开头。进入目录和正文页眉页脚，核对“链接到前一节”处于关闭状态。在测试副本中修改一节页眉，核对其他节。更新整个目录后保存重开，再检查层级、跳转与页码。

报告中的 `requires_layout_check` 表示原生约束及结构检查完成、实际分页待核对。`needs_review` 还包含已识别的异常。Word 保存会规范化默认属性，重复执行可能补回等效 XML 属性，分节和尺寸须保持稳定。

Word 在对象组合超过单页时会继续排版，因此同页约束需要与对象尺寸及实际预览共同检查。[Microsoft KeepNext 说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.keepnext?view=openxml-3.0.1)
