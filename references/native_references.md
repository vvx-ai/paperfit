# 原生交叉引用与参考文献自动编号

## 默认流程

全文 `run`、`reviewed-template` 默认启用 `native_references: true`，编号和样式处理后再转换引用。明确不转换时，在审核配置顶层设置 `false`。旧的底层 `format` 不改编号；使用它时由 Skill 接续独立命令：

```sh
python scripts/paperfit.py crossrefs formatted.docx linked.docx
```

必须使用新的输出路径，同时生成 `.report.json`。交叉引用模块不调用外部服务，可在将来的 API 中通过 `convert_parts(parts)` 复用。

## 转换规则

- 图表：仅接受使用原生 Caption/题注段落样式、含相应 `SEQ 图` 或 `SEQ 表` 的题注。手打“图1”“表1”“图2-1”等必须只有一个对应目标。
- 目标书签仅包围标签及编号，不包括后面的题注标题。正文替换为 `REF bookmark \h`，保留前后的“如”“见”、标点和段落内容。
- 文献：唯一“参考文献”/“References”标题下的连续条目，或明确的参考文献条目样式，且标签恰为 `[1]` 到 `[n]`。移除手打标签，添加真正的 `w:numPr` 列表，编号格式 `[%1]`，保留原标签后的空格和全部著录文本。
- 文献引用 `[2]` 等转换为 `REF bookmark \n \h`，显示被引用段落的原生列表序号。`[J]`、`[N]`、日期和 DOI 不作为文献序号转换。
- v0.3.2 起，正文中可确认目标的文献 REF 默认整体上标，包括方括号。新建与既有简单/复杂 REF 都会检查；使用“文献引用”字符样式，保留既有其他字符样式时仅覆盖上标。添加 `\* MERGEFORMAT`，在 Word 更新结果时保留格式。图表引用、周围标点及文末列表不改为上标；不替换为 Unicode 上标字符。复杂或无法确认的域保留并报告。
- 已有域不再次包裹；已处理列表及书签重复执行不重复创建。Word 保存后变成复杂域结构也应保留。
- 缺失、重复或未闭合的书签进入报告。未知自动列表、重启编号、自定义编号格式、组合引用、跨超链接或书签的标签等不自动猜测。当前不支持把任意文献管理器域转成该列表，也不实现完整 GB/T 著录规范化。

## 完整性及实际验收

逐段记录允许的文字变化，核对表格单元格、公式和嵌入对象，原图片资源不改。转换过程中遇到结构歧义保留原状；结构安全检查失败不发布结果。

交付前更新整个目录和所有域，检查显示编号、目标及布局。在单独副本中，在第二条文献前插入一条同级列表项，更新域后原 `[2]` 引用应显示 `[3]`，仍跳到原条目；图表采用相同的新增题注测试。正式稿不得加入测试用内容。

新增文献时在现有列表内按回车接续编号；正文新引用用“交叉引用 → 编号项 → 段落编号（无上下文）”，图表选择对应标签及“仅标签和编号”。修改顺序后全选正文、更新域，并更新整个目录。直接覆盖域结果或删除目标书签会破坏关联，需重新插入引用。

```sh
python -m unittest discover -s tests -p 'test_native_references.py' -v
python -m unittest discover -s tests -v
```

测试覆盖分散文本与校对标记、仅引用编号、相同规则重跑、复杂域保存、目标顺序变化、重复目标、未知列表重启、缺失书签、结构拒绝及禁止覆盖。真实 Word 更新和 WPS 分页需另做应用验收。

Microsoft 说明交叉引用以域保存并需更新：[创建交叉引用](https://support.microsoft.com/en-au/word/create-a-cross-reference)。列表格式中的 `%1` 为第一级编号占位符，周围字符为固定显示内容：[LevelText 文档](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.leveltext?view=openxml-3.0.1)。
