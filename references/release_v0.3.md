## 功能结项矩阵

| 原始目标 | v0.3 交付状态 | 边界 |
| --- | --- | --- |
| 复杂论文模板支持 | 支持模板信息提取、明确样式/节映射及四节学校模板审核适配 | 尚非任意模板自动识别或通用封面迁移 |
| 自动目录与页码 | 原生 TOC、PAGEREF、PAGE 和目录正文分节 | 单节生成入口有前置条件，应用负责计算最终页码 |
| 多节文档处理 | 指定节页面设置、一级标题下一页分节、独立页眉页脚、正文跨章连续页码 | 复杂首页、奇偶页、浮动版面仍需核对 |
| 对话式局部修改 | Agent 把自然语言范围映射为唯一章节和层级，再调用 chapter | 不是任意自然语言全文编辑器；目标存在歧义时停止 |
| 修改前后差异 | 独立 JSON 差异报告、各步骤账本和完整性检查 | Word 会重写等效 XML，不提供像素级或完整语义差异判断 |
| 异常兼容与修复 | 明确范围的目录链接修复、共享样式预检、旋转图片同页、输入和覆盖保护 | 不自动修复所有损坏 DOCX，不绕过签名或文档保护 |

Phase 1/2 已有功能继续保留。文献处理支持基础编号、缩进、字体及引用对应检查，完整 GB/T 7714 著录规范化仍未实现，不能作为已完成能力宣传。扫描规范 OCR 也不在当前实现中。

## 已吸收的问题

- 样式不能只靠外观判断，正文和标题必须绑定真实段落样式，避免直接格式覆盖。
- 封面、正文、题注和目录不能因共享样式产生意外联动；局部修改需要检查继承影响。
- 题注用原生 Caption 与 SEQ 图/表；标签注册和交叉引用可见性需在用户应用中验证。
- Word 新增或粘贴内容仍可能引入直接格式，文档本身不能永久阻止，需重跑统一与校验。
- 同页要求要结合旋转后的图片尺寸、短表高度及实际打印预览。超长表格需要续表或另行布局。
- 一级标题分页与正文页码重启是两件事，只有正文首节从 1 开始，后续章节连续。
- XML 结构检查、应用视觉检查和用户验收分别记录，不能相互替代。

## 使用和交接

维护入口是 `scripts/paperfit.py`。各命令 `--help` 都可独立查看，旧 Python API 保留。`reviewed-template` 作为四节模板入口加入统一调度，原独立脚本继续兼容。

`smoke_test.py` 在不存在的新目录中生成合成样例，验证公共命令流水线、重复执行、媒体和表格保留以及原文件保护。样例不是学校规范模板，无需引用用户论文即可复现运行检查。

`build_release.py` 用文件白名单生成本地 ZIP，附包级 SHA-256 和包内 MANIFEST.json。包含 scripts、tests、当前 references、README、SKILL、VERSION 和依赖清单。不会打包 output、历史用户文档、缓存、虚拟环境或本机绝对路径配置。未包含第三方字体、Office/WPS 或 Python 依赖安装文件，不是离线运行器。

本版本未发布公共仓库或 PyPI，也未自动安装或替换用户已有 Skill。
